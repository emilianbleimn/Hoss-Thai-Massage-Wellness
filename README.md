# Hoss Thai Massage & Wellness – Website

Statische One-Page-Website (HTML/CSS/JS, keine Build-Tools) für Hoss Thai Massage & Wellness in Groß-Zimmern.
Design angelehnt an einen dunklen, eleganten Spa-Stil (Anthrazit `#272A33`, Beige-Gold `#CDB595`).

Lokal ansehen: `index.html` im Browser öffnen oder `python3 -m http.server` starten.
